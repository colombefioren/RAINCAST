# Third cloud session (23 and 24 October), built with build_kernel_queue.py --gpu --runs-per-gpu 3 and started
# with build_cloud_job.py. Every plain 12- to 16-epoch U-Net++ of the second session landed at 0.710 to 0.711 (last-k
# average, tuned thresholds) and the plain U-Net at 0.7095 in a quarter of the time, so more seeds of them add
# little on their own. This session first tests four ways to a better single model from random weights, each
# against that 0.710 to 0.711 band:
# - a resnet50 encoder (the best single epoch of the ImageNet-weight runs);
# - batch 32 with learning rate 2e-3 (larger steps, better use of the 96 GB GPU);
# - 2x instead of 3x input upscaling (2.25 times cheaper if it holds up);
# - shifted-copy test-time augmentation (each epoch also logs the score of the same model without it);
# then trains validation and full-data pairs of U-Net and U-Net++ for the ensemble, as many as the 10.25 hours
# allow (the launcher skips runs that would not end in time). Validation seeds are 6xx; each full-data twin is
# the seed + 100. The twins of the four tests come after the first pairs, once the tests have run.
