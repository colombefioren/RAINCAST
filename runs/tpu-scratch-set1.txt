# Training runs for the first Kaggle TPU session (build_kernel_tpu.py), in priority order.
# Every model starts from random weights (rule 2.5). Each validation run (scored on the Dec 2022 - Mar 2023
# season, trained on the other months) has a "full" twin with the same settings trained on every month: the
# validation run chooses thresholds and ensemble weights, the twin makes the test predictions.
base: --data /kaggle/input/competitions/hackathon-IndabaX-MDG-2026 --out /kaggle/working --threads 4 --save_each --keep_epochs 6 --tta 0 --lr 1e-3 --aug 2 --dropout 0.2 --bs 16 --upscale 3 --amp 1 --eval_bs 32
